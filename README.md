# Carsharing Management System (Система управління мережею каршерінгу)


## Домен:
*Платформа короткострокової оренди автомобілів.*

## Мета: 
*Автоматизація повного циклу оренди авто без участі фізичних менеджерів чи передачі ключів. Система охоплює:*
* Відстеження вільних автомобілів та їхнього стану (рівень пального, локація) у реальному часі.
* Процес бронювання та віддаленого розблокування дверей (через автомобільну телематику).
* Автоматичну тарифікацію (час/кілометраж) та інтеграцію з платіжними сервісами.

## Взаємодії:
* **Клієнт** — шукає, бронює, використовує авто та оплачує послугу.
* **Зовнішні сервіси** — банк для списання коштів та Google Карти для відображення геолокації.

## Артефакти проєкту (результати розробки):
* Концептуальна (лише бізнес-логіка, проміжні таблиці чи технічні деталі **відсутні**) ER-модель даних (сутності, атрибути та зв'язки).
